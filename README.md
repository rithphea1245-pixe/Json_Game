# 🌟 Words-Of-Wonder

A feature-rich Java application and backend project designed for interactive puzzle and quiz gameplay.

-haha

## 🚀 Features
* **Interactive UI:** Built with custom Java screens for smooth user navigation.
* **Dynamic Gameplay:** Includes word search, sorting games, and quizzes.
* **Robust Backend:** Manages server-side logic and database connectivity.
* **Database Integration:** Utilizes a structured SQL schema for storing game data and scores.

---

## 🛠️ Tech Stack
* **Language:** Java
* **Database:** SQL / Relational Database
* **Environment:** Linux / VS Code
